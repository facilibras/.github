A Facilibras é uma plataforma web voltada ao ensino e à prática da Língua Brasileira de Sinais (Libras). 
Ela oferece exercícios práticos nos quais os usuários realizam sinais diante da webcam, recebendo feedback sobre a correção dos movimentos, incluindo orientações quanto à precisão dos sinais executados.
